# Ejercicio 06 - Login con QtDesigner

Este repositorio contiene la evolución de la aplicación de Login para la materia Programación Orientada a Objetos. En esta entrega, se optimizó el flujo de trabajo integrando **QtDesigner** para el diseño visual de la interfaz, manteniendo la lógica de control en los archivos fuente de C++.

## 🚀 Características del Proyecto
* **Diseño Visual Eficiente:** Uso del editor `.ui` de QtCreator para arrastrar y posicionar los elementos gráficos de manera ágil.
* **Form Layouts Elásticos:** Implementación de contenedores visuales alineados que se adaptan automáticamente al tamaño de la ventana de la Mac.
* **Seguridad Visual:** Configuración de la propiedad `echoMode` en modo `Password` para ocultar la clave en pantalla mediante puntitos.
* **Conexión Limpia:** Vinculación de los componentes del diseño con el código mediante sus respectivas propiedades `objectName` (`txtUser`, `txtPass`, `btnEntrar`).
