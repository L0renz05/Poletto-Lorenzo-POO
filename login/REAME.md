# Ejercicio 05 - Login sin QtDesigner

Este repositorio contiene el desarrollo de una aplicación de Login para la materia Programación Orientada a Objetos. En esta entrega, la interfaz gráfica de usuario (UI) fue codificada **completamente a mano** utilizando C++ y el framework Qt, sin el uso de herramientas de diseño visual.

## 🚀 Características del Proyecto
* **Interfaz por Código Puro:** Creación e instanciación manual de componentes (`QLineEdit`, `QPushButton`, `QLabel`).
* **Gestión de Layouts:** Organización elástica de la ventana mediante código utilizando layouts verticales y horizontales.
* **Señales y Slots:** Implementación manual de la conexión `connect` para validar las credenciales del usuario de forma dinámica.
